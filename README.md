# 单细胞药物扰动响应预测

课程研究项目：基于 Kaggle 公开比赛 [Open Problems – Single-Cell Perturbations](https://www.kaggle.com/competitions/open-problems-single-cell-perturbations)（2023）的训练数据，预测已知药物在已知细胞类型中的多基因响应统计量。核心方法是把"按药物计算的平均响应"与"多输出岭回归"做加权融合，融合权重与正则化参数在验证集上联合选择。该方法是对既有简单方法的探索性组合，不声称提出新的基础算法。

## 模型简介

- **输入**：细胞类型与药物名称（独热编码）。
- **输出**：18,211 个基因的有方向差异表达统计量 `-log10(p) × sign(log-fold change)`。
- **融合**：`预测 = (1−λ)·药物均值 + λ·岭回归`，在验证集上从 25 个 (α, λ) 组合中选参，选参后合并训练与验证集重拟合。
- **局限**：仅在"已见药物 × 已见细胞类型"的组合留出上评估，未验证未知药物、新细胞类型或新供体的泛化。

## 主要结果

MRRMSE（逐行均方根误差均值，3 次随机划分的均值±样本标准差，越低越好）：

| 设置 | 药物均值 | 完整岭回归 | 融合模型 |
| --- | ---: | ---: | ---: |
| 常规组合留出 | 1.3498 ± 0.0893 | 1.2952 ± 0.0372 | **1.2636 ± 0.0643** |
| NK 细胞少样本 | **1.2576 ± 0.0754** | 1.4274 ± 0.0441 | 1.2512 ± 0.0928 |

各设置复用同一数据集、划分相互重叠，且模型在观察先前结果后设计，以上均为探索性结果，不是独立验证。补充的五个随机划分与四种目标细胞的少样本实验见 `实验结果/` 与 `补充随机划分评估.py`。

```

├── 补充实验.py                  # MLP、NK 少样本、细胞分组误差

├── 跨细胞相关性探索.py          # 同药物跨细胞响应相关性
├── 药物均值岭回归融合实验.py    # 融合模型验证选参与测试
├── 补充随机划分评估.py          # 五个新随机划分的敏感性分析

├── 实验结果/                    # 固定划分与全部结果文件
```

## 快速开始

环境：Windows / Python 3.10，依赖见 `requirements.txt`。

```powershell
python -m pip install -r requirements.txt
# 按 Kaggle 比赛规则下载 de_train.parquet 放入 数据/（见 数据/数据获取说明.md）
python 数据审计.py 数据/de_train.parquet --out 数据审计结果.json
python 实验.py
python 补充实验.py
python 公平比较与误差分析.py
python 多细胞少样本探索.py
python 跨细胞相关性探索.py
python 药物均值岭回归融合实验.py
python 补充随机划分评估.py
```

按上述顺序运行会重新生成 `实验结果/` 中后续脚本需要的划分与结果；随机种子固定（42、123、2026 与补充划分 17、314、2718、3407、2027），硬件或依赖版本差异可能带来微小数值浮动。

## 预训练模型与预测

仓库附带预训练模型 `模型/fusion-seed42.joblib`（参数说明见 `模型/fusion-seed42.json`，示例输出见 `模型/示例预测.csv`），可直接预测，无需重训：

```powershell
python 预测.py --cell "NK cells" --drug "Clotrimazole" --output 预测结果.csv
```

如需从数据重建模型（使用 seed 42 选出的参数 alpha=100、λ=0.75，在全部 614 行上重训）：

```powershell
python 训练保存模型.py
```

只支持训练时出现过的药物与细胞类型，未知类别会报错。重训模型使用了全部数据，不能再把同一数据当作独立测试集。
